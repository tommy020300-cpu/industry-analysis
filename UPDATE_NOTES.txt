IO Studio · 사용성 개선판 (PC 중심)

적용한 원칙
- 배경 #F2F4F6, 흰색 카드, 파란색 강조 #3182F6
- 명확한 대비와 큰 핵심 제목·지표 / 불필요한 장식과 테두리 최소화
- 산업명은 말줄임표 없이 줄바꿈해 전체 표시
- 카드형 산업 선택: 추천 산업 → 검색 → 명시적 선택
- 금액 간편 선택: 10억/50억/100억/1,000억 + 직접 입력
- 원자료: 표 12개를 카드로 선택한 뒤 행·열 검색, 셀 클릭 상세보기
- 계산 방법: 3단계 설명 + 필수 근거와 한계 표시
- 쉽고 짧은 해요체 안내, 결과가 예측되는 버튼 문구
- 검색 입력 중 자동으로 산업이 바뀌지 않도록 수정
- 기존 한국은행 데이터, 계산식, 시뮬레이션 기능 유지

참고
- 독립적인 교육용 GitHub Pages 웹사이트예요. 앱인토스 입점용 SDK/브랜드 로고/탭바 가이드는 적용 대상이 아니에요.
- 토스가 소유한 그래픽·로고·이모지는 포함하지 않았어요. 기존 프로젝트의 자체 제작 3D 이미지만 유지했어요.

GitHub 업로드
- 바뀐 파일은 src/App.tsx, src/index.css 두 개예요.
- ZIP 압축을 풀고 src 폴더 '안의' 두 파일을 GitHub 저장소의 src 폴더에 업로드하세요.
- Commit changes → Actions / Publish IO Studio 초록색 체크 확인 → 사이트 Ctrl + Shift + R.

검증
- 데이터 분류 33/83/165/380개와 각 12개 표 검증 통과.
- 기존 시뮬레이션 계산 예제 독립 검증 통과.
- TSX/TS 파서 검증 통과.
- npm 패키지 설치가 제한되어 전체 React 프로덕션 빌드·브라우저 테스트는 수행하지 못했어요.
