# 산업연관 인사이트 — 2023년 산업연관표 웹앱

> 산업조직론 과제물 1 | **GitHub Pages 기반 산업연관표 분석 웹앱**

한국은행의 **2023년 산업연관표(연장표)** 원본 엑셀을 바탕으로 산업의 생산·수입·부가가치 유발효과를 분석하고, 산업별 중간재 거래 관계와 상세 표를 탐색하는 웹앱입니다. 별도 서버나 유료 호스팅 없이 정적 GitHub Pages에서 실행됩니다.

## 2. 데이터 출처

- 제공처: **한국은행**, 「2023년 산업연관표(연장표)」, 2025. 9. 24. 발표.
- 기준: **2023년**, **생산자가격** 및 **2020년 실측표를 기준년으로 한 연장표**.
- 경제통계시스템(ECOS): <https://ecos.bok.or.kr>
- 공식 원문: `data/source/2023-bok-io-report.pdf`
- 원본 엑셀: `data/source/io-large.xlsx`, `io-medium.xlsx`, `io-small.xlsx`, `io-basic.xlsx`
- 상품분류 참고자료: `data/source/product-classification.xlsx`
- 한국은행 제공 요약 통계표: `data/source/2023-bok-summary-tables.xlsx` (참고자료, 계산에는 원본 투입산출표 4종 사용)

사이트의 2023년 전산업 생산유발계수 **1.827**, 부가가치유발계수 **0.752**, 수입유발계수 **0.248**은 한국은행 보도자료에 발표된 **최종수요 가중 계수**로, 개별 산업별 계수의 단순평균이 아닙니다.

```text
    │   ├── 2023-bok-summary-tables.xlsx
    │   └── 2023-bok-io-report.pdf

        ├── large.json
        ├── medium.json
        ├── small.json

        └── summary.json
```

웹페이지는 **한국은행 원본 엑셀에서 값과 행·열 정보를 사전 추출한 JSON**을 로드합니다. 원본 Excel도 저장소에 동봉해 버튼으로 내려받아 원자료와 대조할 수 있습니다. JSON은 서버 비용 없이 빠르게 검색하기 위한 저장 형식입니다. 원자료를 변경하면 `python scripts/build_data.py`로 JSON을 재생성합니다.

### 데이터 로딩 절차

1. 상단에서 **산업 분류 기준**을 선택합니다.
2. **2023년 산업연관표 불러오기**를 누릅니다(처음에는 대분류 자동 로딩).
3. `data/processed/{분류}.json`을 읽고 12개 시트·산업명·코드·계수를 준비합니다.
4. **원본 엑셀**을 누르면 해당 분류의 한국은행 엑셀 파일을 내려받을 수 있습니다.

> 고용계수나 취업유발계수는 별도의 한국은행 고용표가 있어야 합니다. 이 과제의 제공 Excel에 고용표가 없으므로 **고용 창출인원은 계산하지 않습니다.**

## 4. 계산 방법

### 생산유발효과

국산투입계수 행렬을 \(A_d\), 산업별 국산품 최종수요 변화 벡터를 \(\Delta Y\), 생산유발계수(레온티에프 역행렬)를 \(L=(I-A_d)^{-1}\)라고 할 때,

\[
\Delta X=L\Delta Y.
\]

특정 산업 \(j\)에서 100억 원의 수요가 증가하면 \(\Delta Y_j=100\)이고 나머지 산업의 최종수요 변화는 0입니다. 산업 \(i\)에서 유발되는 생산은 \(L_{ij}\times100\)억 원입니다. 전체 생산유발액은 \(\sum_i L_{ij}\times100\)억 원입니다.

### 부가가치·수입유발효과

원본 부가가치유발계수 행렬 \(V^*\), 수입유발계수 행렬 \(M^*\)를 사용합니다.

\[
\Delta V=V^*\Delta Y,\qquad \Delta M=M^*\Delta Y.
\]

따라서 시뮬레이터의 금액 단위는 **억 원**, 계수는 **무차원**입니다. 두 산업의 비교는 각 계수행렬의 해당 열을 산업별로 합산한 값으로 수행합니다.

### 산업 간 거래

국산거래표에서 행은 **재화를 공급하는 산업**, 열은 **그 중간재를 사용하는 산업**입니다. 사용 산업 \(j\)의 중간재 구매 목록은 \(Z^d_{ij}\) 열로, 공급 산업 \(i\)의 주요 구매처는 \(Z^d_{ij}\) 행으로 분석합니다. 수입중간재 비율은 국내·수입 거래액 합계 중 수입 거래액의 비중입니다.

## 5. 해석상의 한계

- 2023년의 투입구조와 산업기술이 변하지 않고, 생산능력 제약이 없으며, 가격 변화가 없다는 **정태적 투입산출모형**의 가정하에 계산합니다.
- 정책으로 인한 실제 부가가치/GDP 증가율이나 **고용유발효과를 직접 예측하지 않습니다**.
- 수치의 기준연도는 2023년이며 미래의 물가 변화를 반영하지 않습니다.
- 정부가 발표한 전산업 평균과 개별 산업 유발계수는 서로 다른 가중 방식을 사용하므로 구분합니다.
- 한국은행 데이터는 반올림되어 있어 분류 간 항목의 합이 근소하게 다를 수 있습니다.

## 6. 웹사이트 배포 (GitHub Pages)

**중요: ZIP 파일만 저장소에 업로드하면 웹사이트가 되지 않습니다. 압축을 풀고 내부 파일과 `data`, `scripts` 폴더 구조 그대로 저장소 최상위에 업로드해야 합니다.**

1. GitHub에 로그인하고 본인 저장소의 **Code** 탭으로 이동합니다.
2. **Add file → Upload files**를 선택합니다. 파일 업로드 화면에 압축 해제한 `index.html`, `style.css`, `app.js`, `worker.js`, `model.py`, `.nojekyll`, `README.md`와 **`data/`, `scripts/` 하위 전체 파일**을 올립니다. 단순 ZIP 업로드는 불가합니다.
3. **Commit changes** 또는 **Propose changes**를 눌러 main 브랜치에 반영합니다. (GitHub 화면에 따라 버튼 이름이 다를 수 있습니다.)
4. 저장소의 **Settings → Pages**로 이동합니다.
5. `Build and deployment`에서 **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**로 설정하고 저장합니다.
6. GitHub Pages가 배포되면 `https://사용자이름.github.io/저장소이름/`으로 접속합니다. Actions 탭에서도 게시 상태를 확인할 수 있습니다.
7. **4개 산업 분류**, **12개 시트**, **검색**, **계산**, **원본 엑셀 다운로드**를 각각 확인합니다.

### 로컬 실행

`index.html`을 파일 탐색기에서 직접 두 번 눌러 `file://`로 열면 브라우저의 보안 정책 때문에 `fetch()`가 차단될 수 있습니다. 이때는 해당 폴더에서 아래와 같이 로컬 HTTP 서버를 실행합니다.

```bash
python -m http.server 8000
```

그 후 <http://localhost:8000> 에서 테스트합니다. 실제 제출은 GitHub Pages 주소를 사용합니다.

## 7. 기술 구조

- HTML, CSS, Vanilla JavaScript: 정적 배포, 화면 및 사용자 입력
- Python 표준 라이브러리(`zipfile`, `xml.etree.ElementTree`): Excel 원본의 수치·분류정보 전처리
- Pyodide + Web Worker: 시뮬레이션 시 **선택적 Python 교차검증**(CDN 연결 가능할 때)
- 계산의 기본 표시: JavaScript가 동일 원본 계수 행렬을 이용하므로 Pyodide CDN에 연결되지 않아도 작동
- 입력 데이터: 한국은행 2023년 산업연관표, 외부 상업용 분석 API 불필요
