# 2023년 산업연관분석 웹앱

한국은행 **「2023년 산업연관표(연장표)」**의 생산자가격 기준 투입산출표를 활용하는 교육용 분석 도구입니다. 브라우저에서 산업별 유발계수와 중간재 거래구조를 확인하고, 국산품 최종수요 증가 시나리오의 경제적 파급효과를 계산합니다.

## 실행 및 배포

1. GitHub 저장소를 `Public`으로 설정합니다.
2. 이 저장소의 모든 파일과 `data/`, `scripts/` 하위 폴더를 **압축을 풀어 저장소 최상위**에 올립니다. `index.html`은 최상위에 두어야 합니다.
3. `Settings → Pages → Deploy from a branch → main → / (root) → Save`에서 공개합니다.
4. 게시된 `https://<사용자이름>.github.io/<저장소이름>/` 주소에서 웹앱을 엽니다.

정적 웹페이지이므로 별도의 서버 설치가 필요하지 않습니다. JavaScript는 브라우저에서 원자료를 읽어 계산합니다. Python(Pyodide) 검증은 별도의 외부 CDN 연결이 가능할 때에만 선택적으로 실행되며, 연결되지 않아도 JavaScript 분석은 계속 사용할 수 있습니다.

## 분석 기능

| 메뉴 | 구현 내용 |
|---|---|
| 종합 현황 | 한국은행 공표 전산업 계수(생산 1.827, 부가가치 0.752, 수입 0.248), 산업별 유발계수 순위와 비교 |
| 파급효과 분석 | 산업 검색, 여러 산업 수요 증가액 누적·삭제·초기화, 생산·수입·부가가치 효과 동시 계산, 산업별 생산유발액 순위, 결과 CSV |
| 산업 간 거래 | 선택 산업의 주요 국내 중간재 공급 산업/구매 산업, 국산·수입 중간재 비중 |
| 산업 비교 | 두 산업의 생산·수입·부가가치 유발계수, 총·수입 중간투입계수 비교 |
| 원자료 탐색 | 원본 12개 시트 선택, 행/열 코드·이름 검색, 페이지 탐색, 개별 셀 값 조회, CSV 내려받기 |
| 자료·분석 방법 | 원자료 출처, 계산식, 분석 단위 및 한계 설명 |

### 산업 분류별 데이터

| 분류 | 산업 개수 | 파일 |
|---|---:|---|
| 통합대분류 | 33 | `data/processed/large.json` |
| 통합중분류 | 83 | `data/processed/medium.json` |
| 통합소분류 | 165 | `data/processed/small.json` |
| 기본부문 | 380 | `data/processed/basic.json` |

각 분류는 **12개 원본 시트**를 포함하며, 한국은행 공개 Excel은 `data/source/`에 함께 들어 있습니다.

## 파급효과 시뮬레이션 사용법

1. 화면 위쪽의 산업 분류를 선택합니다.
2. **파급효과 분석** 탭에서 산업명을 검색해 산업을 선택합니다.
3. 최종수요 증가액을 **억 원 단위**로 입력합니다. 예를 들어 10억 원이면 `10`을 입력합니다. 원본 거래표 단위인 백만원과 혼동하지 마세요.
4. **시나리오 추가**를 누릅니다. 다른 산업을 추가할 수 있고 동일 산업을 여러 번 추가하면 자동으로 금액이 합산됩니다.
5. **파급효과 계산**으로 총생산·부가가치·수입 유발액을 확인하고, 필요하면 **계산 결과 CSV 저장**을 누릅니다.
6. 시나리오가 하나도 없다면 파급효과 계산 버튼은 현재 선택한 산업과 금액을 한 번 추가한 후 계산합니다.

### 계산 원리

국산품 최종수요 변화 벡터를 \(\Delta Y\), 국산투입계수 행렬을 \(A_d\)라 하면:

- 생산유발액: \(\Delta X=(I-A_d)^{-1}\Delta Y\)
- 수입유발액: 한국은행의 수입유발계수 행렬 \(M^*\Delta Y\)
- 부가가치유발액: 한국은행의 부가가치유발계수 행렬 \(V^*\Delta Y\)

실제 구현에서는 `data/processed/*.json`에 보존한 한국은행의 **유발계수 행렬**의 열에 각 산업별 수요 증가액을 곱하고 산업별로 합산합니다. 따라서 자체적으로 역행렬을 재추정하는 방식이 아닙니다. 사용자 입력은 억 원이며 계산 결과도 억 원입니다.

> 원본 거래액 표는 백만원, 투입계수·유발계수는 무차원입니다. 일부 수입 중심·국내 생산이 없는 부문의 유발계수는 0으로 기록되어, 국산품 최종수요 증가 가정으로 해당 부문의 국내 생산 파급효과를 산출할 수 없습니다. 이 경우 결과 화면에 안내를 표시합니다.

## 계산 해석 시 주의

- **2023년 투입구조가 고정**된 정태적 시뮬레이션입니다. 가격, 생산능력, 기술 변화, 대체효과가 반영되지 않습니다.
- 기업·소비자 행동에 대한 예측이나 실제 GDP·취업 증가율 예측 모형이 아닙니다.
- 공표 전산업 평균계수는 최종수요 가중 평균치이며, 각 개별 산업의 유발계수 산술평균과 다릅니다.
- 원본 거래액은 백만원 단위이고, 원본 수치의 반올림 때문에 합계가 일부 다를 수 있습니다.
- GitHub 공개 저장소에는 공개 가능한 공식 자료만 업로드하고 개인정보·비밀번호·API 키를 포함하지 않습니다.
